# Fonts & Licensing

The Kaaj design system uses self-hosted open-source fonts under permissive open-source licenses (SIL Open Font License OFL-1.1 and Apache License 2.0).

## 1. Newsreader (Editorial Serif)
- **Author**: Production Type (Florian Runge, Leslie Usherwood)
- **License**: SIL Open Font License, Version 1.1 (OFL-1.1)
- **Usage**: Editorial headings, Kaaj wordmark, display typography, classic serif spine font.
- **Package**: `@fontsource/newsreader`

## 2. Kalam (Handwritten Caption)
- **Author**: Indian Type Foundry (Lipi Raval)
- **License**: SIL Open Font License, Version 1.1 (OFL-1.1)
- **Usage**: Paper-strip captions, catalogue labels, handwritten annotations, spine date labels, handwritten spine font.
- **Package**: `@fontsource/kalam`

## 3. Special Elite (Typewriter / Slab)
- **Author**: Astigmatic
- **License**: Apache License, Version 2.0
- **Usage**: Typewriter stamped text, spine font option.
- **Package**: `@fontsource/special-elite`

## 4. Oswald (Condensed Display)
- **Author**: Vernon Adams, Kalapi Gajjar, Cyreal
- **License**: SIL Open Font License, Version 1.1 (OFL-1.1)

## 5. Playfair Display (High-Contrast Serif)
